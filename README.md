# Market Analysis Notebooks

Python analyses built alongside my MSc in Business Analytics and Financial Technology
at the University of Dundee.

## Contents

**Bitcoin drawdown analysis** — quantified a 66.9% peak-to-trough drawdown over 10.6 months
($47,687 to $15,787) across the 2022–2023 cycle, using a cumulative-maximum method on daily
closing prices.

**Portfolio backtest** — 5-week equity portfolio returns against the FTSE 100 benchmark,
with per-holding performance attribution.

**Tesco PLC DCF valuation** — 5-year FCFF discounted cash flow at a 7.66% WACC with terminal
value, producing a £51.8bn enterprise value and 565p intrinsic value. Rebuilt in Python and
validated against the Excel model from a university valuation project.

## Tools
Python · Pandas · yfinance · matplotlib
